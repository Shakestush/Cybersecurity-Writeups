## Format

Every writeup follows the same structure so they're easy to skim:

1. **Objective** — what the room/module is teaching
2. **Methodology** — step-by-step approach with the actual commands run
3. **Screenshots** — evidence of each step
4. **Key Takeaways** — what carries over to real engagements
5. **Mitigations** (where applicable) — the defensive side of the same finding
